
# Crafter Online Design Platform

**A web platform for young and creative designers to learn, practice, share, and get feedback on UI/UX design.**

Crafter is designed to help aspiring designers master UI/UX skills through **hands-on projects, community interaction, and feedback mechanisms**. Whether building small websites or larger applications, this platform emphasizes practical learning and portfolio building.


## 🎯 Focus Areas

* **📚 Learn:** Understand UI/UX fundamentals with structured guides and resources.
* **🏗️ Apply:** Complete mini-projects to practice concepts and gain confidence.
* **🤝 Share:** Showcase designs and contribute to the community for collaboration.
* **🔥 Feedback:** Receive and give feedback to improve design quality.

---

## ⭐ Features

1. User account creation and personalized portfolio tracking
2. Create, edit, update, and delete UI/UX posts
3. Feedback system for posts and blogs
4. Create blogs and share knowledge
5. Download project starter files for hands-on practice
6. Comprehensive guides covering:

   * UI/UX stats and trends
   * Tools used in UI/UX design
   * Curated learning resources

---

## ⚙️ Tech Stack

* **Frontend:** Angular, TypeScript, SCSS, Bootstrap
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Other:** REST APIs, AJAX
